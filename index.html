One-time setup

Before this browser can save a roll or a drawing, it needs the access key for the site. Whoever set this up has it — paste it below. You only do this once on this device, and you can look around without it.

Setting this up for the first time?

The key is a GitHub fine-grained personal access token for . Only one is needed for the whole site — make it once and share it with the other artist.

  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → this one
  3. Repository permissions: Contents → Read and write
